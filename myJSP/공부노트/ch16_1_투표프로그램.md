# ch16 — 투표 프로그램 (Poll)

`guestbook`/`ch15`가 "글 하나"를 중심으로 돌아갔다면, `ch16`은 **"설문 하나에 항목 여러 개가 딸린" 1:N 구조**를 다룹니다. 그리고 그 항목들 중 **여러 개를 한 번에 선택해서 서버로 보내는 법**(체크박스 배열)을 처음 제대로 다루는 챕터이기도 합니다.

---

## 1. 구조 — 설문(PollList) 1개에 항목(PollItem) 여러 개

```sql
create table tblPollList(
 num int primary key auto_increment,   -- 설문 번호
 question varchar(200) not null,        -- 질문
 sdate date, edate date,                -- 시작일/종료일
 type smallint default 1,               -- 1=복수선택, 0=단일선택
 active smallint default 1              -- 진행중(1)/종료(0)
);

create table tblPollItem(
 listnum int not null,      -- 어느 설문 소속인지 (tblPollList.num을 가리킴)
 itemnum smallint default 0, -- 그 설문 안에서 몇 번째 항목인지 (0부터)
 item varchar(50) not null,  -- 항목 내용 ("짜장면" 등)
 count int,                  -- 득표수
 primary key(listnum, itemnum)  -- 두 컬럼을 합쳐야 유일한 값이 됨
);
```

`tblPollItem`의 기본키가 `listnum` 하나가 아니라 **`(listnum, itemnum)` 두 컬럼을 합친 복합키**라는 게 포인트입니다. "3번 설문의 0번 항목"과 "5번 설문의 0번 항목"은 `itemnum`만 보면 둘 다 0이라 겹치지만, `listnum`까지 같이 봐야 진짜로 다른 행이라는 걸 알 수 있기 때문입니다.

## 2. 설문 등록 — 부모(설문) 먼저, 자식(항목) 나중

```java
// PollMgr.insertPoll()
sql = "insert tblPollList(question,sdate,edate,wdate,type) values(?,?,?,now(),?)";
int cnt = pstmt.executeUpdate();

if(cnt==1) {  // tblPollList 저장이 성공했을 때만
    int listNum = getMaxNum();  // 방금 저장한 설문의 num (auto_increment 값)
    String item[] = piBean.getItem();
    for (int i = 0; i < item.length; i++) {
        if(item[i]==null || item[i].trim().equals("")) break;  // 빈칸 항목은 무시
        sql = "insert tblPollitem values(?, ?, ?, 0)";
        pstmt.setInt(1, listNum);
        pstmt.setInt(2, i);       // 배열 인덱스가 그대로 itemnum이 됨
        pstmt.setString(3, item[i]);
    }
}
```

**부모(설문)를 먼저 저장해서 `num`을 확보한 다음, 그 번호를 자식(항목)들의 `listnum`으로 물려줍니다.** `pollInsert.jsp`에서 항목 입력칸을 8개(`<input name='item'>` 8번) 만들어두고, 다 안 채워도 되게(빈 칸에서 반복문을 `break`) 만든 것도 이 로직과 맞물립니다.

## 3. 단일선택 vs 복수선택 — 태그만 다르고 `name`은 같다

```jsp
<%-- pollForm.jsp --%>
<%if(type==1){%>
    <input type="checkbox" name="itemnum" value="<%=i%>">   <%-- 복수선택 --%>
<%}else if(type==0){ %>
    <input type="radio" name="itemnum" value="<%=i%>">      <%-- 단일선택 --%>
<%}%>
<%=item%><br>
```

`PollListBean.type`(1 또는 0) 값 하나로 태그 종류만 바꿔치기하고, `name="itemnum"`은 두 경우 다 똑같이 씁니다. 그래야 다음 단계(투표 처리)에서 **체크박스든 라디오든 완전히 같은 코드로 받을 수 있습니다.**

## 4. 여러 개 선택값을 한 번에 받기 — `getParameterValues`

체크박스로 여러 개를 고르면, 같은 이름(`itemnum`)의 파라미터가 **여러 번** 넘어옵니다. 지금까지 써온 `request.getParameter("이름")`은 이런 경우 **첫 번째 값 하나만** 돌려주기 때문에 못 씁니다.

```java
// pollFormProc.jsp
String itemNum[] = request.getParameterValues("itemnum");  // 배열로 전부 받음
boolean result = mgr.updatePoll(listNum, itemNum);
```
```java
// PollMgr.updatePoll()
for (int i = 0; i < itemNum.length; i++) {
    sql = "update tblPollItem set count = count + 1 where listNum = ? and itemNum = ?";
    pstmt.setInt(1, listNum);
    pstmt.setInt(2, Integer.parseInt(itemNum[i]));
    pstmt.executeUpdate();
}
```
단일선택(라디오)이어도 이 코드는 그대로 동작합니다 — 배열 길이가 1일 뿐, `getParameterValues`는 라디오/체크박스 구분 없이 항상 배열을 돌려주기 때문입니다. **"값이 여러 개일 수 있다"는 가능성 자체를 항상 배열로 다루면, 단일/복수 선택을 같은 코드로 처리할 수 있다**는 게 핵심입니다.

## 5. "설문 번호가 없으면 최신 설문을 보여준다" — `num==0` 관례

```java
// PollMgr.getItemList()
if(listNum==0) {           // 설문을 아예 선택하지 않은 경우
    listNum = getMaxNum(); // 가장 최근(번호가 가장 큰) 설문으로 대체
}
```
`num` 파라미터가 없을 때 `int num = 0`으로 초기화해두고, DB 조회 메소드들(`getPoll`, `getItemList`, `getSumCount`, `getView`, `getMaxCount`) 전부 **"0이면 최신 설문으로 대신 조회"** 하는 규칙을 똑같이 반복합니다. `int`는 `String`과 달리 `null`이 될 수 없어서, "값이 없다"는 걸 표현할 방법으로 **0이라는 값 자체를 "없음"으로 약속**해 쓴 것입니다 (0번 설문이 실제로 존재할 일이 없다는 전제 — `auto_increment`는 1부터 시작하니까 안전합니다).

## 6. 결과 계산 — 비율과 "0으로 나누기" 함정

```java
int ratio = sumCnt==0 ? 0 : (int)(Math.round((double)count/sumCnt*100));
```
투표수 비율을 `count / sumCnt * 100`으로 구하는데, **아직 아무도 투표 안 한 설문(`sumCnt==0`)을 결과보기로 열면 0으로 나누기가 발생**합니다. 정수 나눗셈이 아니라 `double` 나눗셈이라 예외가 나지는 않지만, `0.0/0.0`은 `NaN`, `count>0`인데 `sumCnt==0`인 경우는 `Infinity`가 되고, 이걸 반올림해서 `int`로 형변환하면 화면에 이상한 숫자가 찍힙니다. **"분모가 될 수 있는 값은 항상 0인 경우를 먼저 확인"** 하는 게 안전합니다.

## 7. 시각화 — 비율을 막대 길이로

```jsp
<div class="bar-track">
    <div class="bar-fill" style="width:<%=ratio%>%; background:<%=rgb%>;"></div>
</div>
```
`ratio`(0~100 사이 정수)를 막대의 `width`에 퍼센트로 그대로 꽂으면, 숫자를 별도로 변환할 필요 없이 **비율 값 자체가 곧 막대 길이**가 됩니다. 항목마다 다른 색을 주고 싶으면 배열로 색상 목록을 만들어두고 `i % 배열길이`로 순환시키면, 항목이 몇 개든 안전하게(배열 범위를 안 벗어나고) 색을 배정할 수 있습니다.

## 8. 오늘 정리

1. **다대일(N:1) 관계는 자식 테이블의 기본키를 복합키로** — `(listnum, itemnum)`처럼 "부모 번호 + 순번"을 합쳐야 자식들끼리 구분됩니다.
2. **부모를 먼저 저장해 번호를 확보한 뒤 자식에 물려주는 순서**를 지켜야 관계가 성립합니다.
3. **체크박스/라디오처럼 "여러 개 또는 하나"가 넘어올 수 있는 값은 `getParameterValues()`로 항상 배열로 받으면**, 단일/복수 케이스를 같은 코드로 처리할 수 있습니다.
4. **정수형 파라미터의 "값 없음"은 0 같은 특정 값으로 약속**해두고 처리하는 것도 실무에서 흔한 패턴입니다 (단, 그 값이 실제 데이터와 절대 겹치지 않는지 확인 필요).
5. **나눗셈이 들어가는 계산은 분모가 0일 가능성부터 확인**하는 습관을 들일 것.
