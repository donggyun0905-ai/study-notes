# ch05-2. 상태에 따라 위젯 바꿔치기 — 버튼 ↔ 진행 표시기

> 예제: `ch05/lib/main4.dart`
> **"버튼을 누르면 로딩 표시로 바뀌는" 실무에서 가장 많이 쓰는 패턴**

---

## 1. 만들 것

```
[다운로드]  ──터치──▶  ◌ (빙글빙글)  ──3초 후──▶  [다운로드]
 ElevatedButton      CircularProgressIndicator
```

---

## 2. 전체 코드

```dart
//main4.dart

import 'package:flutter/material.dart';

void main() => runApp(MyApp());

class MyApp extends StatefulWidget {
  const MyApp({super.key});

  @override
  State<MyApp> createState() => _MyAppState();
}

class _MyAppState extends State<MyApp> {

  //다운로드 중인지 여부를 담는 상태 변수
  bool isDownloading = false;

  //버튼을 눌렀을 때 실행되는 함수
  void download() {
    setState(() {
      isDownloading = true;//버튼 -> 진행 표시기로 변경
    });

    //실제 다운로드 대신 3초 기다리기
    Future.delayed(const Duration(seconds: 3), () {
      if (!mounted) return;//화면이 사라진 뒤 setState 하면 에러
      setState(() {
        isDownloading = false;//다시 버튼으로 되돌리기
      });
    });
  }

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title:'ch05',
      home:Scaffold(
        appBar: AppBar(title:Text('Subject')),
        body:Center(
          //상태 변수에 따라 보여줄 위젯을 바꿔준다
          child: isDownloading
              ? CircularProgressIndicator()
              : ElevatedButton(
                  onPressed: download,
                  child: Text('다운로드'),
                ),
        )
      )
    );
  }
}
```

---

## 3. ★★ 핵심 원리 — build()는 매번 다시 실행되는 함수다

```dart
child: isDownloading
    ? CircularProgressIndicator()   // 참이면 이 위젯
    : ElevatedButton(...)           // 거짓이면 이 위젯
```

지금까지는 상태 변수를 **위젯의 속성**에 꽂아 넣었습니다 (`value: isChecked`).
이번엔 **위젯 자체를 교체**합니다.

```
isDownloading = false  →  build() 실행  →  ElevatedButton 을 만들어 돌려줌
       │
   setState로 true
       │
       ▼
isDownloading = true   →  build() 재실행 →  CircularProgressIndicator 를 만들어 돌려줌
```

**`build()`는 "지금 상태에서 화면이 어떤 모습이어야 하는지"를 계산해서 돌려주는 함수**입니다. 그러니 그 안에서 if문/삼항 연산자로 분기해도 전혀 문제가 없습니다. 오히려 이게 Flutter의 기본 사고방식입니다.

> **명령형 vs 선언형**
> - (다른 프레임워크) "버튼을 숨기고, 로딩바를 보여라" ← 명령형
> - (Flutter) "다운로드 중이면 화면은 로딩바다" ← **선언형**. 상태만 바꾸면 화면은 따라옴

### 조건부 위젯 3가지 표기법

```dart
// ① 삼항 연산자 — 둘 중 하나 (가장 많이 씀)
child: isDownloading ? CircularProgressIndicator() : ElevatedButton(...)

// ② children 안에서 조건부 삽입
children: [
  Text('제목'),
  if (isDownloading) CircularProgressIndicator(),   // 참일 때만 추가됨
  Text('내용'),
]

// ③ 함수로 분리 — 조건이 3개 이상일 때
child: buildBody(),
...
Widget buildBody() {
  if (isDownloading) return CircularProgressIndicator();
  if (isDone) return Text('완료!');
  return ElevatedButton(...);
}
```

## 4. CircularProgressIndicator — 두 가지 모드

| 코드 | 모양 | 언제 |
|---|---|---|
| `CircularProgressIndicator()` | 계속 빙글빙글 (**무한**) | 얼마나 걸릴지 모를 때 |
| `CircularProgressIndicator(value: 0.7)` | 70%에서 멈춘 원 | 진행률을 알 때 |

```dart
CircularProgressIndicator(
  value: 0.7,                    // 0.0 ~ 1.0 (null이면 무한 회전)
  color: Colors.blue,            // 진행 색
  backgroundColor: Colors.grey,  // 남은 부분 색
  strokeWidth: 8,                // 굵기
)
```

**막대 형태**가 필요하면 `LinearProgressIndicator()` — 속성은 동일합니다.

> `value`에 **0~100이 아니라 0.0~1.0**을 넣습니다. 70%는 `0.7`. 실수하기 쉬운 부분.

## 5. 함수로 분리하기 — `onPressed: download`

```dart
void download() { ... }      // ① 함수 정의 (State 클래스 안)

onPressed: download,         // ② 괄호 없이 함수 이름만!
```

[ch04-4](./ch04_4_기본위젯_버튼_Text_Icon.md)에서 배운 `onPressed: iconButtonOnPressed`와 같은 패턴입니다.

| 코드 | 결과 |
|---|---|
| `onPressed: download` | ✅ 누를 때 실행 |
| `onPressed: download()` | ❌ 화면 뜰 때 바로 실행 + 타입 에러 |

**처리가 2줄 이상이면 함수로 빼는 게 좋습니다.** `build()` 안이 깔끔해지고, 같은 동작을 여러 버튼에서 재사용할 수 있습니다.

## 6. Future.delayed — 가짜 비동기 작업

```dart
Future.delayed(const Duration(seconds: 3), () {
  // 3초 뒤에 실행될 코드
});
```

`Future.delayed(기다릴시간, 그다음할일)` — **지정한 시간 뒤에 함수를 실행**합니다.

### Duration 표기
```dart
const Duration(seconds: 3)
const Duration(milliseconds: 500)
const Duration(minutes: 1, seconds: 30)
```

### ★ 화면이 멈추지 않는다 (중요)

`Future.delayed`는 **기다리는 동안 앱이 멈추지 않습니다.** 3초 동안에도 스크롤·터치가 다 됩니다. 그래서 로딩 애니메이션도 계속 돌아갑니다.

> 실제 앱에서는 이 자리에 서버 통신(`http.get`)이나 파일 저장이 들어갑니다. 지금은 그걸 배우기 전이라 "3초 기다리기"로 흉내낸 것입니다.

## 7. ★ `mounted` 체크 — 왜 필요한가

```dart
Future.delayed(const Duration(seconds: 3), () {
  if (!mounted) return;   // ← 이 줄이 없으면 에러 가능
  setState(() { isDownloading = false; });
});
```

### 사고 시나리오

```
0초 : 다운로드 버튼 누름 → 3초 타이머 시작
1초 : 사용자가 뒤로 가기로 화면을 닫음 → 위젯이 사라짐(State 소멸)
3초 : 타이머가 setState 호출 → 이미 없는 위젯을 다시 그리라고 요청 → 💥 에러
```

```
Unhandled Exception: setState() called after dispose()
```

| 표현 | 의미 |
|---|---|
| `mounted` | **이 위젯이 아직 화면에 붙어 있나?** (true/false) |
| `if (!mounted) return;` | 안 붙어 있으면 아무것도 하지 말고 끝내기 |

**규칙: `await`나 `Future.delayed` 뒤에 `setState`를 쓸 때는 반드시 `mounted`를 확인합니다.** 이번 예제는 3초라 재현하기 쉽지만, 서버 통신은 언제 끝날지 모르니 더 중요합니다.

## 8. 흔히 하는 실수

### ① 버튼을 여러 번 누를 수 있다
지금 코드는 다운로드 중에 버튼이 사라지므로 안전합니다. 하지만 버튼을 **남겨두는** 디자인이라면 중복 실행을 막아야 합니다:

```dart
ElevatedButton(
  onPressed: isDownloading ? null : download,   // 다운로드 중이면 비활성화
  child: Text('다운로드'),
)
```
`onPressed: null`은 **회색 비활성 버튼**이 됩니다 ([ch04-4](./ch04_4_기본위젯_버튼_Text_Icon.md) 참고).

### ② 로딩 중에 버튼 크기가 바뀌어 화면이 덜컥거린다
`CircularProgressIndicator`와 버튼의 크기가 달라서 레이아웃이 움직입니다. 크기를 고정하면 해결됩니다:

```dart
SizedBox(
  width: 150, height: 48,
  child: Center(child: isDownloading ? CircularProgressIndicator() : ElevatedButton(...)),
)
```

### ③ `setState`를 한 번만 부르고 끝냄
`true`로 바꾸는 `setState`와 `false`로 되돌리는 `setState` — **두 번** 필요합니다. 되돌리는 걸 빠뜨리면 영원히 로딩 중입니다.

## 9. 다음 단계로 확장해보기

| 하고 싶은 것 | 방법 |
|---|---|
| 진행률을 실제로 표시 | 상태 변수 `double progress = 0.0` 추가 → `Timer.periodic`으로 0.1씩 증가 → `CircularProgressIndicator(value: progress)` |
| 완료 알림 띄우기 | `ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text('완료!')))` |
| 완료 후 버튼 글자 바꾸기 | 상태를 `bool` 대신 `enum DownloadState { idle, loading, done }`로 — 3단계 이상이면 enum이 깔끔 |
| 진짜 다운로드 | `http` 패키지 (`pubspec.yaml`에 추가) → `await http.get(...)` |

### enum으로 3단계 관리하는 예

```dart
enum DownloadState { idle, loading, done }

DownloadState state = DownloadState.idle;

// build() 안에서
child: switch (state) {
  DownloadState.idle    => ElevatedButton(onPressed: download, child: Text('다운로드')),
  DownloadState.loading => CircularProgressIndicator(),
  DownloadState.done    => Text('완료!'),
},
```

`bool` 하나로는 2가지 상태만 표현되므로, 3가지 이상이면 **enum**을 씁니다 ([ch05-1](./ch05_1_입력위젯_Checkbox_Radio_Dropdown.md)의 `Gender`와 같은 문법).

## 10. 정리 — 오늘 배운 패턴

```dart
// 1. 상태 변수
bool isDownloading = false;

// 2. 상태를 바꾸는 함수
void download() {
  setState(() { isDownloading = true; });     // 시작

  Future.delayed(Duration(seconds: 3), () {   // 오래 걸리는 일
    if (!mounted) return;                     // 안전 장치
    setState(() { isDownloading = false; });  // 끝
  });
}

// 3. 상태에 따라 다른 위젯
child: isDownloading ? CircularProgressIndicator() : ElevatedButton(onPressed: download, ...)
```

**이 3단 구조가 "로딩 처리"의 기본형**입니다. 서버에서 데이터를 받아오는 모든 화면이 이 모양입니다.
