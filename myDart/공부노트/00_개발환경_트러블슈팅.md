## 3. ★ main.dart가 아닌 파일 실행하기

Flutter의 기본 진입점은 **`lib/main.dart` 하나로 고정**입니다. `main2.dart`를 그냥 실행하려 하면 안 됩니다.

### 방법 ① 터미널에서 `-t` 옵션
```bash
flutter run -t lib/main2.dart
```

### 방법 ② Android Studio
- 파일을 열면 `void main()` 왼쪽 여백에 **▶ 아이콘**이 생김 → 클릭
- 또는 상단 실행 구성 → `Edit Configurations...` → **Dart entrypoint**를 `lib/main4.dart`로 변경

> **▶ 아이콘이 안 보이면 `main()` 함수가 없는 것**입니다. (아래 트러블슈팅 ① 참고)

## 4. 오늘 겪은 에러 3건

### ① `Error: Could not find 'main'` — 실행 자체가 안 됨

**증상**: `main3.dart`를 실행하려는데 아무 반응이 없고, 실행 버튼도 안 보임.

**원인**: 파일에 진입점이 없었다.
```dart
// 이 한 줄이 빠져 있었음
void main() => runApp(MyApp());
```

**교훈**: Dart 프로그램은 **반드시 `main()`에서 시작**합니다. 클래스를 아무리 잘 만들어도 `main()`이 없으면 실행할 지점이 없습니다. 새 파일을 만들 때 가장 먼저 쓸 줄.

---

### ② 드롭다운을 골라도 화면이 안 바뀜

**증상**: `DropdownButton`에서 '두번째'를 선택했는데 계속 '첫번째'로 표시됨. 에러는 없음.

**원인**: `setState` 안이 비어 있었다.
```dart
onChanged: (value){
  setState(() {
    // 여기가 비어 있었음!
  });
},
```

**해결**:
```dart
onChanged: (value){
  setState(() {
    selectedValue = value!;   // 값을 직접 바꿔줘야 한다
  });
},
```

**교훈 ★**: `setState()`는 **"화면을 다시 그려라"는 신호일 뿐**입니다. 값을 바꿔주는 건 내 몫입니다.
- `setState` 없이 값만 바꿈 → 값은 변했지만 **화면이 안 바뀜**
- 값은 안 바꾸고 `setState`만 호출 → 다시 그렸지만 **결과가 똑같음** (← 이번 경우)

---

### ③ 라디오 버튼 컴파일 에러 (3가지가 겹침)

```dart
// 문제 코드
Gender gender = Gender.MAN;     // ← Gender가 정의 안 됨
...
onChanged: (Gender? value){
  setState((){ gender = value; });   // ← Gender?를 Gender에 대입
}
```

| 원인 | 해결 |
|---|---|
| `enum Gender`를 만들지 않고 사용 | `enum Gender { MAN, WOMAN }` 추가 |
| `Gender?`(null 가능)를 `Gender`에 대입 | `gender = value!;` |
| 두 번째 항목 라벨이 복붙 때문에 '남자' | '여자'로 수정 |

## 5. Hot Reload vs Hot Restart ★

| | 단축키 | 하는 일 | 상태(변수 값) |
|---|---|---|---|
| **Hot Reload** | `r` / `Ctrl+\` | 바뀐 코드만 반영 | **유지됨** |
| **Hot Restart** | `R` / `Ctrl+Shift+\` | 앱을 처음부터 다시 | **초기화됨** |

- 위젯 모양·색·텍스트 수정 → **Reload**로 충분 (거의 즉시)
- `initState` 수정, 상태 변수 초기값 변경, `main()` 수정 → **Restart** 필요
- 체크박스를 켜둔 상태로 Reload하면 켜진 상태가 그대로 남습니다. 초기 상태를 테스트하려면 Restart.

## 6. 에러 찾기 — `flutter analyze`

실행 전에 문법 오류를 미리 잡습니다.

```bash
flutter analyze                 # 프로젝트 전체
flutter analyze lib/main4.dart  # 특정 파일만
```

출력 등급을 구분해서 읽어야 합니다:

| 등급 | 의미 | 조치 |
|---|---|---|
| `error` | **실행 불가** | 반드시 고쳐야 함 |
| `warning` | 실행은 되지만 위험 | 고치는 게 좋음 |
| `info` | 스타일 권고 / deprecated 안내 | 무시해도 동작함 |

오늘 `main2.dart`에서 본 info 2종:
- `The constant name 'MAN' isn't a lowerCamelCase identifier` → enum 상수를 `man`, `woman`으로 쓰라는 권고. 교재 표기를 따랐으므로 무시.
- `'groupValue' is deprecated ... Use a RadioGroup ancestor` → Flutter 3.32부터 권장 방식이 바뀜. 아직 동작은 함.

## 7. 와이파이로 실제 휴대폰 연결하기

**NDK는 무선 연결과 무관합니다.** NDK는 C/C++ 컴파일용이고, 기기 연결은 **`adb`(platform-tools)**가 담당합니다.

### 조건
| 조건 | 현재 상태 |
|---|---|
| platform-tools 30.0.0 이상 | ✅ 37.0.1 (`adb pair` 지원 확인) |
| 휴대폰 Android 11 이상 | 폰 설정 → 휴대전화 정보에서 확인 |
| 폰과 PC가 같은 와이파이 | — |

### 순서
1. 폰: 설정 → 개발자 옵션 → **무선 디버깅** 켜기
2. 폰: 무선 디버깅 → **페어링 코드로 기기 페어링** → IP·포트·6자리 코드 표시
3. PC (최초 1회만):
   ```bash
   adb pair 192.168.0.x:포트번호
   # 프롬프트가 뜨면 6자리 코드 입력
   ```
4. 연결 — **무선 디버깅 메인 화면의 포트**를 씁니다 (3번의 페어링 포트와 다름!):
   ```bash
   adb connect 192.168.0.x:5555
   ```
5. 확인 후 실행:
   ```bash
   adb devices
   flutter run
   ```

> `adb`가 PATH에 없으면 전체 경로로:
> `C:\Users\<사용자>\AppData\Local\Android\Sdk\platform-tools\adb.exe`

> Android 10 이하는 `adb pair`가 없어서, USB로 한 번 연결한 뒤 `adb tcpip 5555` → `adb connect`를 쓰는 구형 방식만 가능합니다.
