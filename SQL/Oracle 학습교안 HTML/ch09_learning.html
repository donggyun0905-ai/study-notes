01

복합키(Composite Key)

두 개 이상의 컬럼을 묶어 하나의 기본키로 지정하는 방식입니다. 각 컬럼은 단독으로 중복될 수 있지만, 조합은 유일해야 합니다.

create table ex2(
 num  int,
 name char(10),
 PRIMARY KEY(num, name)
);
원본 코드(ex1) 오류 확인 — 업로드된 스크립트의 ex1 테이블 정의는 컬럼이 하나뿐인 상태로 괄호가 닫히지 않아 구문 오류가 있습니다(문법적으로 미완성 코드). 강의 시에는 "단일 컬럼 PK는 컬럼 뒤에 바로 PRIMARY KEY를 붙이거나, 테이블 정의 마지막에 PRIMARY KEY(컬럼명)으로 따로 지정한다"는 정상 예시로 교정해서 보여주는 것을 권장합니다.
02

시퀀스(SEQUENCE) — 자동 증가값 생성기

MySQL의 AUTO_INCREMENT와 달리, Oracle은 시퀀스 객체를 별도로 만들고 .NEXTVAL로 다음 값을 꺼내 씁니다.

CREATE TABLE sample_product(
 prdouct_id  number,
 product_name varchar(30),
 manu_date   date
);

CREATE SEQUENCE sam_seq;

insert into sample_product values(sam_seq.nextval, 'television', to_date('140101', 'YYMMDD'));
insert into sample_product values(sam_seq.nextval, 'washer',     to_date('150101', 'YYMMDD'));
insert into sample_product values(sam_seq.nextval, 'cleaner',    to_date('160101', 'YYMMDD'));
commit;
NEXTVAL vs CURRVAL — NEXTVAL은 호출할 때마다 값을 1씩 증가시켜 새 번호를 발급하고, CURRVAL은 그 세션에서 마지막으로 발급받은 값을 다시 조회합니다(NEXTVAL을 먼저 한 번 호출해야 사용 가능).
03

ALTER TABLE — 테이블 구조 수정

-- 컬럼 추가
alter table sample_product add (factory varchar(10));

-- 컬럼 자료형/길이 수정
alter table sample_product modify (product_name varchar(10));

-- 컬럼명 변경
alter table sample_product rename column factory to factory_name;

-- 컬럼 삭제
alter table sample_product drop column factory_name;
절동작
ADD컬럼 추가
MODIFY자료형/길이/제약 변경
RENAME COLUMN ... TO ...컬럼명 변경
DROP COLUMN컬럼 삭제
확인 명령어 — 구조 변경 후에는 DESC sample_product;로 바로 결과를 확인하는 습관이 좋습니다.
04

삭제 3형제 — DELETE vs TRUNCATE vs DROP

delete from sample_product;        -- 행만 삭제, 테이블 구조는 유지, ROLLBACK 가능(DML)
TRUNCATE TABLE sample_product;    -- 전체 행 삭제, 구조는 유지, ROLLBACK 불가(DDL)
drop table sample_product;        -- 테이블 자체(구조+데이터) 완전 삭제
명령분류구조 유지ROLLBACK속도
DELETEDML✅ 유지✅ 가능느림(행 단위 로깅)
TRUNCATEDDL✅ 유지❌ 불가빠름
DROPDDL❌ 삭제됨❌ 불가빠름
가장 중요한 함정 — TRUNCATE와 DROP은 DDL이라 실행 즉시 자동 커밋되어 ROLLBACK으로 되돌릴 수 없습니다. 실습 시 "구조까지 지울지, 데이터만 지울지"를 학생들이 명확히 구분하도록 강조가 필요합니다.
